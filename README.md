International Airbnb Dashboard (Power BI)
Interactive Power BI dashboard to analyse international Airbnb performance. Discovering seasonal trends and key drivers of price, customer reviews and trust.

This project has involved analytical thinking, data modelling and DAX to create insights from the raw data provided by the Airbnb dataset. This analysis has focused on gaining an understanding of how the seasonality affects performance, pricing, trustworthiness of hosts and customer reviews.

Analysis

Identify seasonal trends.
Price
Discover price trends.

In depth analysis of customers reviews.
International Performance
Compare performance between major global destinations.
