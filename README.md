# International Airbnb Performance Dashboard

An interactive **Power BI dashboard** exploring global Airbnb performance, with a focus on seasonality, pricing patterns, host credibility, customer reviews, and destination-level comparisons.

The project applies data cleaning, data modelling, DAX, and visual analytics to turn raw Airbnb data into insights that can support a better understanding of the short-term rental market.

## Project Overview

The dashboard explores five key areas:

- **Seasonality:** Identify changes and patterns in Airbnb performance over time.
- **Pricing Analysis:** Explore listing price patterns and differences across markets.
- **Host Credibility & Trust:** Examine host verification, profile completion, and other available trust indicators.
- **Customer Reviews:** Analyse customer review activity and ratings.
- **International Performance:** Compare performance across major global destinations.

## Analytical Approach

1. **Data preparation:** Clean and transform the source data using Power Query.
2. **Data modelling:** Organise the data and establish relationships for analysis.
3. **Measure development:** Use DAX to create analytical measures and KPIs.
4. **Exploratory analysis:** Investigate seasonality, pricing, host credibility, reviews, and market performance.
5. **Visualisation:** Build an interactive Power BI dashboard to communicate the findings.

2. Open it using **Microsoft Power BI Desktop**.
3. If Power BI asks for a data source or file path, provide the required source dataset and update the connection.
4. Refresh the data, if the source is available, to explore the report.

> **Note:** The repository includes a Power BI template (`.pbit`) and a PDF report. The template may require the original dataset or source connection to be configured before the report can be refreshed.
