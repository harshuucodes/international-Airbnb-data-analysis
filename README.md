# International Airbnb Performance Dashboard | Power BI

An interactive Power BI dashboard designed to analyze international Airbnb performance, uncover seasonal travel patterns, and explore key factors influencing pricing, customer reviews, and guest trust.

This project combines analytical thinking, data modeling, and DAX to transform raw Airbnb data into meaningful business insights. The analysis focuses on understanding how seasonal demand, pricing strategies, host credibility, and customer feedback shape Airbnb's performance across different cities and time periods.

### Key Analysis Areas
- **Seasonality Analysis:** Identifying seasonal trends and variations in travel demand across different destinations.
- **Pricing Insights:** Exploring pricing patterns and their relationship with listing performance.
- **Trust & Host Credibility:** Analyzing host verification, profile completeness, and other trust-related indicators.
- **Review Analysis:** Conducting an in-depth analysis of customer reviews to understand guest experiences, ratings, and changing travel patterns.
- **International Performance:** Comparing Airbnb performance across major global destinations.

### Technical Skills
- Power BI
- DAX (Data Analysis Expressions)
- Data Modeling
- Data Visualization
- Business Intelligence
- Analytical Thinking

The objective of this project is to turn Airbnb data into actionable insights that help understand customer behavior, market trends, and the dynamics of the global short-term rental industry.
