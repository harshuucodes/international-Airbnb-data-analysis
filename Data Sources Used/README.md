# Data Sources Used

This folder contains the data dictionaries supplied with the International Airbnb Performance Dashboard project. They document the fields used in the listings and reviews datasets.

## Files

- [Listings Data Dictionary](Listings_data_dictionary.csv) — describes listing details, host attributes, property information, pricing, and review-score fields.
- [Reviews Data Dictionary](Reviews_data_dictionary.csv) — describes the identifiers and date field in the reviews data.

## Data attribution

These files document the dataset structure; they do not identify the original hosting website or provide a dataset download URL. The exact source platform and dataset link should be added here once confirmed. This avoids attributing the data to an unverified source.
